### 🚀 Descripción del Proyecto

**IP Intelligence Terminal** es una herramienta avanzada de análisis de red e identidad diseñada para profesionales de ciberseguridad y analistas de datos. Proporciona una interfaz tipo "terminal" de alta tecnología para investigar nodos de red, identidades civiles y registros comerciales en tiempo real.

---

### 🛠️ Características Principales

- **🌐 Inteligencia de Red (IP/Domain):** Análisis profundo de IPs y dominios, detectando VPNs, Proxies, Tor y centros de datos.
- **🆔 Inteligencia DNI:** Búsqueda avanzada de identidades civiles (nombres, apellidos, direcciones) mediante integración con APIs de consulta.
- **🏢 Inteligencia RUC:** Consulta de registros comerciales, estados de contribuyentes y actividades económicas.
- **🛒 Inteligencia de Ventas:** Módulo de seguimiento de comprobantes y facturación con desglose de productos.
- **📊 Dashboard de Riesgo:** Visualización interactiva de amenazas mediante gráficos de Recharts.
- **🗺️ Mapa Geoespacial:** Localización física de nodos de red con Leaflet.
- **📱 1000% Responsive:** Interfaz optimizada para móviles con menú lateral inteligente y navegación fluida.
- **🌓 Temas Dinámicos:** Soporte completo para modo oscuro y claro con estética Cyberpunk.

---

### 🔌 Integraciones API

El sistema utiliza protocolos de comunicación con infraestructuras globales:
- **IPQuery API:** Análisis de reputación y geolocalización de red.
- **ConsultasPeru API:** Inteligencia de identidad (DNI/RUC).
- **Cloudflare DNS:** Resolución de dominios mediante DNS-over-HTTPS.

---

### 📱 Experiencia Móvil

Diseñado para analistas en movimiento. El menú lateral permite saltar rápidamente entre secciones de inteligencia (DNI, RUC, Ventas) con un solo toque, manteniendo la potencia de la terminal en la palma de tu mano.
